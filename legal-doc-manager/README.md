# Sistema de Gestión Documental para Bufetes Legales

## Descripción
Sistema completo de gestión documental para bufetes de abogados con control de acceso, bloqueo de documentos en tiempo real, seguimiento de cambios y auditoría completa.

## Características Principales
- ✅ Gestión segura de documentos confidenciales
- ✅ Control de acceso por roles y permisos
- ✅ Bloqueo de documentos en tiempo real
- ✅ Seguimiento de tiempo de trabajo por abogado
- ✅ Sistema de versiones de documentos
- ✅ Auditoría completa de todas las acciones
- ✅ Notificaciones en tiempo real
- ✅ Encriptación de archivos sensibles
- ✅ Interfaz web moderna y responsive

## Tecnologías Utilizadas

### Backend
- Node.js + Express
- SQLite con WAL mode
- JWT para autenticación
- Socket.io para tiempo real
- Multer para manejo de archivos
- Crypto-js para encriptación

### Frontend
- React 18
- Material-UI
- Socket.io Client
- React Router
- React Query
